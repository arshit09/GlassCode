Voice memos go here.

Put recordings from your glasses (m4a, mp3, wav, aac, ogg, opus, webm ...) in this folder
while "2 - Start" is running. A memo that starts with "Claude, ..." is run as a command for
Claude Code. Any other memo is saved as a note.

Results (a small .md text file per memo) and the original recordings move to the "done" folder.
